# Бюджет на продукты

Минималистичный трекер бюджета на продукты для двух человек. Одна HTML-страница, без фреймворков и бэкенда — вся логика на клиенте.

**Живая версия:** https://josegment.github.io/grocery-budget/

## Параметры

- Общий бюджет: 664 zł (можно менять прямо в приложении — карандаш ✎ рядом с суммой)
- Период: 27 июля — 22 августа 2026 включительно (27 дней)
- Недельный бюджет: доля общего пропорционально дням недели (обновляется вместе с общим)

## Возможности

- Быстрое добавление траты: сумма, заметка и, по желанию, фото (снимок сжимается и хранится в браузере)
- Остаток до конца периода, дней осталось и средний расход в день
- Недельный блок с прогресс-баром (зелёный → оранжевый → красный по мере приближения к лимиту)
- История трат с датой, суммой, заметкой и миниатюрой фото; редактирование (✎) и удаление (✕) каждой записи

## Хранение данных

- Траты — в `localStorage` браузера, фотографии — в `IndexedDB`.
- Данные хранятся **на каждом устройстве отдельно** и никуда не отправляются.
- Внимание: браузер (особенно на iOS) может очистить локальное хранилище. Важные данные стоит периодически резервировать.

## Разработка

Приложение — единственный файл [`index.html`](index.html). Достаточно открыть его в браузере; сборка не нужна. Деплой — GitHub Pages из ветки `main`.
